# Публичный SDK: совместная работа

- В этом публичном репозитории сохранять переносимый SDK и его публичный
  контракт; секреты, приватный контекст и реальные данные компаний не публиковать.
- Перед каждым commit/push проверять текущую ветку, git status, working/staged
  diff и незавершённые Git операции, выполнять свежий fetch целевого remote
  и сравнивать обе стороны истории. Stage только проверенные изменения задачи.
- Разошедшуюся общую историю объединять обычным merge, сохраняя все коммиты.
  Не переписывать опубликованную историю rebase/reset/amend и не применять
  force push/force-with-lease без отдельного прямого разрешения пользователя.
- Чужие незавершённые правки не отменять и не включать в свой коммит. Для
  параллельных задач предпочитать отдельную ветку и отдельный git worktree.
- После non-fast-forward обновить remote refs, объединить новые изменения,
  проверить затронутые сценарии и повторить обычный push. После публикации
  проверить сохранность исходных коммитов и remote ref.
